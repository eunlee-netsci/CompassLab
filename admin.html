사이트 관리

구성원·소식·논문 목록을 폼으로 편집합니다. 편집 결과는 브라우저 안에만 있고, 아래 버튼으로 파일을 내려받아 커밋하거나 GitHub에 바로 저장할 수 있습니다.

보안 안내. 이 페이지는 GitHub Pages에 올라가면 누구나 열 수 있습니다. 하지만 토큰 없이는 아무것도 저장되지 않으므로 편집 화면만 보일 뿐입니다. 토큰은 브라우저에만 저장되며 어디로도 전송되지 않습니다(GitHub API 제외). 걱정되면 admin.html과 assets/js/admin.js를 .gitignore에 넣고 로컬에서만 실행하세요.

토큰 만드는 법

  1. GitHub → Settings → Developer settings → Personal access tokens → Fine-grained tokens
  2. Repository access: Only select repositories → CompassLab만 선택
  3. Permissions → Repository permissions → Contents: Read and write (다른 권한은 불필요)
  4. 만료 기간을 짧게 두고, 만료되면 새로 발급하세요.

토큰을 쓰기 싫으면 각 탭의 “내려받기”로 파일을 받아 리포지토리에 직접 올리면 됩니다. 결과는 완전히 같습니다.
